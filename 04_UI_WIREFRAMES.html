📤 What happens when you click "Send Quote":
▶ Mode A — Existing Customer (current)
  1. POST /estimates to Zoho org ExcelTech Cloud
  2. Custom fields set: cf_central_quote_id
  3. Zoho sends email to billing@acme.com (or Central can override)
  4. Status syncs back via webhooks (sent → viewed → accepted)
  5. On invoice_paid webhook → new Subscription auto-created
▷ Mode B — Lead (would be if toggled)
  1. Lead created in Central (LD-2026-NNNN)
  2. Public quote PDF generated locally (Puppeteer)
  3. Email with /q/<token> link to lead
  4. Lead views → views++ → accepts → notification to sales
  5. Sales clicks "Convert" → atomic Zoho push (Spec §15)
