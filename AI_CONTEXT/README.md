# AI Context Folder

This folder contains the complete context, documentation, and protocols for the project. It is designed to act as the "brain" for any AI coding agent collaborating on this repository.

## Files Directory

* **PROJECT.md:** High-level overview of the software.
* **PRD.md:** Business requirements.
* **TDD.md:** Technical implementation.
* **ARCHITECTURE.md:** Folder structure and application architecture.
* **DATABASE.md:** Database schema and migrations.
* **API.md:** Documentation for every endpoint.
* **CODING_STANDARDS.md:** Naming conventions, architecture rules, formatting, and best practices.
* **CURRENT_STATE.md:** Always represents the latest project status.
* **TASKS.md:** Separates Completed, In Progress, Blocked, and Pending tasks.
* **BUGS.md:** Tracks known issues, severity, status, and resolution.
* **DECISIONS.md:** Records architectural and technical decisions along with reasons.
* **CHANGELOG.md:** Keeps a historical record of all development changes.
* **HANDOFF.md:** Always overwritten at the end of every AI session to provide context for the next session.
* **AI_PROTOCOL.md:** Defines how every AI agent should collaborate, update documentation, and perform handoffs.
* **DEPLOYMENT.md:** Server & deployment process.
* **ENVIRONMENT.md:** Local, staging, production setup.
* **TESTING.md:** Testing strategy.
* **SECURITY.md:** Security guidelines.

## Subdirectories

* **Sessions/**: Historical logs or specific session handoffs.
* **Archive/**: Deprecated documentation or old plans.

## When to Update
- **Every Session:** Update `HANDOFF.md`.
- **Feature Completion:** Update `CURRENT_STATE.md`, `TASKS.md`, `CHANGELOG.md`.
- **Architecture Change:** Update `DECISIONS.md`, `ARCHITECTURE.md`, `TDD.md`.
