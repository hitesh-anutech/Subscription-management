# Project Overview

## Description
This project is a Subscription-based Billing & Renewal Automation System integrated with Zoho Books. It is designed to automate the process of managing customer subscriptions, prorating charges, generating renewal quotes, and handling bulk renewals (especially for customers with hundreds of domains).

## Core Objectives
1. Automate subscription renewals and invoice generation via Zoho Books.
2. Handle complex pricing models (e.g., Price x Quantity) without flat bulk rates.
3. Manage bulk domain renewals efficiently by generating a single Zoho Estimate with an attached Technical Annexure PDF when domains exceed 100.
4. Provide a seamless UI for users to view, filter, and act on subscriptions (e.g., bulk price updates, bulk quoting).

## Target Audience
Internal billing and finance teams who manage customer subscriptions, domain renewals, and Zoho Books invoicing.

## Key Features
- **Subscription Syncing:** Sync customers, items, and subscriptions from Zoho Books.
- **Prorata Calculations:** Automatically calculate prorated charges for mid-cycle subscription changes.
- **Bulk Renewal Quotes:** Group subscriptions by Customer, Item, Organization, Billing Cycle, and End Date Month to generate a single Zoho Estimate.
- **Technical Annexure Generation:** Automatically generate and attach a detailed PDF to Zoho Estimates when renewing 100+ domains.
- **Bulk Price Updates:** Easily update subscription prices in bulk from the dashboard.
